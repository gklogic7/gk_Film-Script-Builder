# 🎬 GK Film Script Builder

A simple interactive movie script planning tool for creating scenes, dialogues, and branching story choices.

## ✨ Features

- 🎥 Create movie scenes
- 🎭 Add character dialogues
- 🌳 Multiple choice story flow
- 🧩 Node-based script planning
- 📋 Export and copy script data
